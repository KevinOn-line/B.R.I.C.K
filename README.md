# B.R.I.C.K

	B.R.I.C.K Boundary Regulation & Intrusion Checking Kit

	Works:
	Raspberry Pi that “connects” to an application and only sends signals yes or no data signals.
	Plug-in USB hardware, Hardware Ex. Keyboards, Mice, Headphones, and any pluggable device
	Checks for any Malware found within the Devices 
	Sends a Signal to the Application on the main laptop to assess possible risks and signs (Basically like "yes for this risk or what not"
	Also serves as a Pi-hole that sends signals to the application and sends pop-ups for any possible foreign attacks
	
	Portable Physical Cybersecurity Protection
